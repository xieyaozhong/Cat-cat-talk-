# 🐈 Cat Cat Talk｜貓咪對話器

一個純前端、手機優先的趣味人貓互動工具，可直接部署到 GitHub Pages。

## 功能

- **人 → 貓**：輸入想說的話，轉換成較適合貓咪理解的語氣、動作與互動提示，並播放瀏覽器即時合成的貓叫聲。
- **貓 → 人**：綜合叫聲、尾巴、耳朵與距離等線索，提供可能的情緒／需求推測。
- **聽貓叫**：取得麥克風權限後，在裝置端分析約 3 秒的音量與頻率特徵；聲音不會上傳。
- **互動紀錄**：使用 localStorage 保存在目前裝置。
- **PWA / 離線**：可加入手機主畫面，快取後可離線開啟基本功能。

## 使用方式

直接開啟 `index.html`，或將 GitHub Pages 指向 `main` branch 的 `/ (root)`。

預期 Pages 網址：

`https://xieyaozhong.github.io/Cat-cat-talk-/`

## 注意

本工具是趣味互動與觀察輔助，不是動物語言的科學逐字翻譯器，也不能取代獸醫或專業動物行為評估。若貓咪突然持續哀叫、呼吸異常、躲藏、明顯食慾下降、排尿困難或行為劇烈改變，應優先處理健康問題。
